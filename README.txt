LookFind Web V0.5

Bu surum Roboflow Serverless Workflow API kullanir. inference-sdk gerekmez.

1) start.bat dosyasini calistirin.
2) Olusan .env dosyasina SerpApi ve Roboflow anahtarlarinizi girin.
3) Asagidaki iki satir aynen kalabilir:
   ROBOFLOW_WORKSPACE=akin-ustabas
   ROBOFLOW_MODEL_ID=yolo-world-small-demo
4) start.bat dosyasini yeniden calistirin.
5) http://127.0.0.1:8000 adresini acin.

API anahtarlarinizi kimseyle paylasmayin.
